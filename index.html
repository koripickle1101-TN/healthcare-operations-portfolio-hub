Patient Access Bottleneck Intelligence System

Excel workbook with workflow map, case-control tracker, accuracy controls, risk matrix, dashboard, glossary, and evidence guide.

I built this project to practice tracing where a front-end patient-access workflow first loses control. It connects a simulated registration inaccuracy with eligibility mismatch, authorization readiness, financial clearance, follow-up, escalation, patient communication, and verified closure.

What it contains: START HERE, WORKFLOW MAP (8 steps), CASE CONTROL (12 simulated cases), ACCURACY CONTROLS, RISK MATRIX, DASHBOARD, GLOSSARY, EVIDENCE GUIDE.

Important: Student-developed, simulated, educational, no-PHI. Does not represent professional healthcare employment.
