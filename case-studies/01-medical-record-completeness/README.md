## The workflow question

**Where did the workflow first lose control?**

A fictional specialist report contains six expected pages, but only five are received and indexed while the processing task is marked complete. The scenario illustrates why a completed indexing step does not necessarily establish document completeness. Some simulated content defects also preserve the expected page count.

## Student project approach

I used a paired set of **500 fictional document records**, including **40 records with modeled defects**, to compare baseline detection outcomes against a hypothetical proposed control. The educational workbook includes synthetic source data, a formula-driven KPI dashboard, an exception log, proposed workflow controls, and methodology/limitations.

| Simulated metric | Baseline | Proposed control |
|---|---:|---:|
| Defects in common dataset | 40 | 40 |
| Detected defects | 25 | 38 |
| Escaped defects | 15 | 2 |
| Detection rate | 62.5% | 95.0% |
| Escape rate | 37.5% | 5.0% |
| Estimated downstream rework | 5.00 hours | 0.67 hours |

**Modeled downstream rework difference:** approximately **4.33 hours**, calculated using an illustrative assumption of 20 minutes per escaped defect. The estimate **excludes proposed checkpoint costs** and **is not net time or labor savings**.

These figures are simulated, not observed healthcare outcomes. The proposed detection scenario is **not a validated intervention** and does not demonstrate real-world clinical, financial, productivity, or patient benefit.
